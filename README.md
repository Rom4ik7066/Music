# Моя музыка

Небольшое Windows-приложение со встроенным окном проигрывателя для
SoundCloud, Яндекс Музыки, Spotify, YouTube и YouTube Music.

## Запуск приложения

Запустите `dist\MyMusic.exe`, вставьте ссылку на трек, альбом, плейлист или
профиль и нажмите **Продолжить**. Кнопка открытия запускает отдельное окно
WebView2, в котором загружается сайт сервиса и можно пользоваться его
обычным проигрывателем.

Python и библиотеки приложения включены в EXE. Для встроенного браузера
необходим Microsoft Edge WebView2 Runtime. Если его нет, приложение предложит
скачать установщик с Microsoft, проверит цифровую подпись и запустит установку.
Нужно подключение к интернету; установка системного runtime может запросить
подтверждение Windows. Войти в аккаунт сервиса нужно внутри окна проигрывателя.

Чтобы запустить из исходников, нужен Python 3 с установленным `tkinter`
(в установщике Python для Windows выберите **tcl/tk and IDLE**). Зависимости
для встроенного окна и сборки описаны в `requirements-build.txt`. Запустите
`app.pyw` двойным щелчком или командой `pythonw app.pyw`.

## Сборка EXE

Запустите `build_exe.bat`. Скрипт проверит наличие Python и Tkinter, затем
автоматически скачает и установит PyInstaller и pywebview из `requirements-build.txt`,
если их ещё нет, и создаст файл `dist\MyMusic.exe`. Если для сборки
не найден Python или Tkinter, скрипт остановится с сообщением: Python и Tkinter
нужны только на компьютере, где выполняется сборка. Для скачивания PyInstaller
нужно подключение к интернету.

## Ограничения

Сайты сервисов загружаются во встроенном окне; авторизация и воспроизведение
работают по правилам самого сервиса. Доступность входа, защищённого контента,
рекламы и воспроизведения зависит от сервиса, аккаунта, региона и лицензий.
Приложение не обходит эти ограничения.
